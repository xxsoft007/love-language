# 爱的五种语言 · 本地版

双击 `index.html` 即可使用，无需安装、注册或联网。请保留同目录的 `style.css`、`data.js`、`app.js`。

已实现丈夫／妻子各30道题库题目、自动前进、返回修改、进度恢复、五维评分、并列主要／次要倾向、五种详细解析、伴侣行动与冲突沟通建议、重新测试、摘要复制、JSON下载、打印保存PDF。

“我们的报告”使用双方最新结果进行对照。另一设备的伴侣可以下载JSON结果文件，再在此页面导入。本地版没有在线邀请码和服务器，不会上传数据。

推荐用同一浏览器、同一路径打开。部分浏览器限制本地文件的存储；保存失败会提示，当前页面仍能完成测试。不要在这种情况下刷新；完成后下载备份。如果需要稳定的浏览器存储，可以在此目录运行 `python -m http.server 8080`，然后访问 `http://localhost:8080`。

打印报告：在结果页点“打印 / 保存PDF”，在打印对话框选择保存为PDF。

这是一项关系沟通练习，不是官方测验或临床诊断。需求偏好不等于关系质量。

技术：原生HTML、CSS、JavaScript，零第三方依赖。页面使用hash路由以兼容双击打开。可在本地继续编辑全部源文件。
